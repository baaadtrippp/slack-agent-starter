This index maps the feature and acceptance IDs in the canonical
[v1 specification](v1.md) to evidence. A feature with no row for an evidence
kind has no evidence of that kind. Test links point at the current tests.
History links point at the milestone (M1–M13) and feature docs as they stood at
commit `718808a`; those docs were removed after that commit. RC is the release
candidate failure and restart checks.

**Date** is the run date when the source states one, otherwise the date the
recording pull request merged. **Tested commit** is given only when the source
names it.

## Evidence rules

For each slice, link evidence and label it as one of:

- **deterministic** — local or CI checks using synthetic fixtures and test
  doubles;
- **provider integration** — real provider behavior without Slack's live
  boundary;
- **live Slack** — an authorized run through the real Slack app and workspace. A
  row whose run used a fake or synthetic worker says so; such a run proves the
  Slack boundary only, not Pi or a model.

State exactly what ran. A fake worker proves gateway routing and error behavior,
not real Pi behavior. A local webhook fixture proves signature handling logic,
not Slack delivery. Provider dashboards or a resource name prove provisioning,
not a working application round trip.
